# Bolloxnuts.com — Project Context

## Purpose
Test site. Showcasing a specific Italian Prosecco wine. Elegant, minimal, premium feel.

## Stack
Plain HTML, CSS, JavaScript. No frameworks, no database, no CMS.

## Design Rules
- Elegant, Italian, premium wine aesthetic
- Colours: deep champagne gold, ivory/cream, soft forest green, charcoal
- Typography: serif for headings, clean sans for body
- No filler content, no generic SaaS cards
- Mobile responsive always
- British English

## Deployment
- GitHub repo: https://github.com/ezzgutu-web/bolloxnuts
- Live server: bolloxnuts.com on 20i hosting
- FTP server: ftp.gb.stackcp.com
- FTP username: bolloxnuts.com
- Deploy via GitHub Actions to 20i via FTP
