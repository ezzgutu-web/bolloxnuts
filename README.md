# Bolloxnuts.com

Prosecco showcase website — built with plain HTML/CSS. Test site for the Sean's web service pipeline.

## Stack
Static HTML, CSS, JavaScript. No frameworks, no database.

## Local Development
Open `index.html` directly in your browser. No server needed.

## Deployment
Push to `main` branch — GitHub Actions automatically deploys to 20i hosting via FTP.

## Structure
- `index.html` — main page
- `.github/workflows/deploy.yml` — auto-deployment pipeline
- `CLAUDE.md` — project context for AI agents
